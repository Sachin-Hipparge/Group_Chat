# Signup and Login Frontend

A simple frontend Signup and Login application built using HTML, CSS, and JavaScript.

## Features

- User signup with name, email, phone number, and password
- Email validation
- 10-digit phone number validation
- Minimum 6-character password validation
- Login using email or phone number
- Login password validation
- User data stored using browser localStorage
- Switch between Signup and Login forms

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Create an account using the Signup form.
4. Login using the registered email or phone number.
